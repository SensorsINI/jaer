jAER

Full-featured desktop application for neuromorphic event cameras and silicon cochleas from iniVation, inilabs, Prophesee, and NRV. Windows, Linux, and macOS. Developed by the Sensors Group, Institute of Neuroinformatics, UZH-ETH Zurich.

Download jAER View on GitHub See Releases

  • macOS Apple Silicon
  • macOS Intel
  • Linux x64

Features

  • Captures USB output from most event cameras (iniVation, Prophesee, NRV, SensorsINI cochleas).
  • Denoises with fast, accurate algorithms.
  • Displays with color, 2D/3D, fading, and sliding-window accumulation (pipeline).
  • Records compressed AEDAT-4, including timed and rotating VCR sessions that can span days.
  • Plays back AEDAT, Metavision RAW/DAT, DSEC HDF5, ROS bags, CSV — with rate control, markers, and IN/OUT points.
  • Processes live or recorded streams with EventFilter chains (auto-built property panels) and application demos.
  • Serves live or recorded data via File → Remote: DNN shared memory, OpenCV HTTP MJPEG / Linux webcam, ROS2 / Foxglove publisher.
  • Exports CSV, HDF5, or AEDAT-4 (Python dataloaders) and MP4 via File → Export video.
