This page lists the mouse gestures and keys most people use every session.
Menu names match the AEViewer menus. Chip classes that add a menu (DAVIS, DVXplorer, …) have their own shortcuts; see Camera chip menus below.

Mouse on the event display

ActionWhat it does
Mouse wheelChange contrast (how bright events appear). Wheel up = more contrast.
FS=X in top bar shows the full scale event count.
Ctrl + mouse wheelZoom in/out around the cursor. Same as View → Zoom in/out.
Right-dragPan the image (2D). In 3D display methods, right-drag moves the origin; left-drag rotates.
Right-clickSelect a pixel to listen to (spike click / selected cell). Click outside the chip to clear.
Shift + mouse wheelJog through a recording (or step if paused). Wheel up = forward.
Shift+Alt + mouse wheelChange playback accumulation (time slice or event count).

Ctrl+= / Ctrl+- zoom; Ctrl+0 unzoom. Up/Down arrows also change contrast.

Camera chip menus

Selecting a DAVIS, DVXplorer, or similar chip adds a menu of that name on the AEViewer menu bar. Those items register accelerators that only exist while that chip is loaded. They use Shift so they do not clash with playback F/S (faster/slower) or display C (color mode).

DAVIS (APS + DVS)

Menu DAVIS. Toggles capture and display together.

KeyAction
Shift+EToggle DVS events (capture and display)
Shift+FToggle APS frames (capture and display)
Shift+HToggle APS histogram overlay
Shift+GToggle global vs rolling shutter
Shift+AToggle APS autoexposure
Shift+Up / Shift+DownIncrease / decrease APS exposure
Shift+Right / Shift+LeftIncrease / decrease APS frame rate
Shift+CToggle APS display autocontrast
Ctrl+Shift+Up / Ctrl+Shift+DownIncrease / decrease APS image contrast
Shift+IToggle IMU capture and display

Full APS/IMU controls are in Interface → hardware configuration (User-Friendly Controls, APS, IMU tabs).

DVXplorer

Menu DVXplorer (event camera; no APS frames).

KeyAction
Shift+EToggle DVS events (capture and display)
Shift+IToggle IMU capture and display

Other chips (DVS128, multi-camera, cochlea, …) may add a named menu without these accelerators. Open that menu to see what it offers.
